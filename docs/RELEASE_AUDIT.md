## 发现与修复

| 范围 | 修复及验证 |
| --- | --- |
| 普通会话隔离 | 角色工具从根层改为会话作用域；显式退出、未知模式和残留鱼 goal 不再获得人格授权；根 registry 的旧适配器别名也在注册前拒绝 |
| 发送授权 | 模型配置工具不能开启发送、修改收件人、关闭审核或削弱预算/环境防护；force不构成授权；人工审核仍需原有发送开关允许 |
| 配置事务 | 锁内合并本次字段，修复多实例覆盖他人配置；严格拒绝畸形布尔、混合危险配置和不安全数字 UID |
| 长 ID | 浏览器文本输入、配置、工具、MCP原始JSON、回复和复核统一保持精度；不能从已舍入数字猜回目标 |
| 登录 | 二维码独立归属、旧请求不能覆盖新账号、网络操作有超时、凭证原子私密落盘 |
| 发送复核 | 有界分页、去环、重复合并、ID保真、损坏状态拒写、锁内合并与日报追加；登录态列表可见不再被描述为保证公开可见 |
| 后台隐私 | stdout/stderr、模型及工具错误只保留白名单元数据，不复制私信、请求正文或堆栈；处理UTF-8拆分和长行 |
| 下载与环境 | CPU/系统选择、官方摘要、大小/时限、独立暂存、实际可执行校验；Python3.11–3.13/Pillow13门禁、旧环境备份及失败恢复 |
| 可选转写 | 只清理本次下载、保留本地输入、同BV并发隔离；导入不修改全局临时目录；可选环境失败/中断不再假就绪 |
| 视频 | 修复编码器管道资源与失效的partial路径；明确目标的估时和实测不足60%时要求重编内容，不用静帧填时 |
| UI与目录 | 修复逻辑失败误报、首次称号误报、可访问名称、焦点循环、环境升级说明、旧响应覆盖；目录打开采用三平台无shell参数和退出确认 |
| 分发 | 主/开发依赖锁定，可移植QA进入Git根，运行manifest仅保留实际存在的check命令，源码ZIP保留开发流程，补齐隐私/部署/发布/素材与CI资料 |

## 真实媒体验证

独立 Pillow 13 / Python 3.12 环境使用当前 `createPv` 协调器实际执行。验收样片目标15秒、最低9秒；最终27.2秒、816/816帧、1920×1080、30fps、AAC，音频RMS约0.1012。四镜口型活动帧分别为137/128/160/145，两比例封面存在；回执的 `verifiedVideo` 指向实际存在的最终 `video.mp4`。首帧、中帧、末帧和封面已目视检查。

时长是目标，不是逐帧固定长度；实际结果随旁白和语速变化。预览和正式制作均不接受严重不足的明确目标计划。媒体校验检查解码、非静音、时序、口型活动和产物存在性，不宣称已进行ASR逐字识别或主观听感认证。

## 宿主、外部与平台边界

- 真实headless one-shot不组合角色预设：宿主门禁证明预设声明可组合和普通模式真实无泄漏；鱼模式工具挂载/退出由真实ScopedLayers源码、goal driver及独立模式测试验证，不冒称操作了当前GUI中的真实鱼会话。
- 基础支持对象为配置完整的本机Desktop/Web profile，须有 `webServer`、`agentPresets`。纯base/headless不能直接承载整个桌宠bundle；内部后台任务使用受控桥。
- macOS/Linux目录启动参数已自动测试，但本轮没有在这些桌面实机操作。CI提供Windows/Linux/macOS、Node22/24、Python3.11/3.12矩阵；配置文件已核验，尚未把未运行的远程CI写成已通过。
- 默认配音的实际样片使用在线语音服务；可选Whisper/yt-dlp和收藏边车为离线接口契约，未下载大型识别模型或执行真实收藏。用户自配GPT-SoVITS/GPU环境、参考音色和ASR识别质量未纳入主依赖审计。
- npm与主Python依赖审计是审查时快照，不是未来版本或所有可选用户环境的无漏洞保证。
- 没有重启正在使用的DSH；修改JS需要用户完全退出并重开后加载。没有更新真实profile、模型凭证、用户权限或删除运行历史。
