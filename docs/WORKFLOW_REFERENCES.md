本插件只读检索与学习实践分开：经验出现在上下文不代表已经使用；角色自己报告“有帮助”不等于平台或人工验证有效。检索不会改批准状态，也不会按点赞量自动强化人格。普通模式不获得角色经验。

两类记忆界面共享同一条学习记录投影：学习队列负责审核与状态，统一记忆视图负责跨来源查看。它们不应互相维护第二本学习账，也不应在没有展示对应内容时额外拉取整份历史。

记忆检索按来源读取。`source=all` 的 `total` 与 `counts` 覆盖当前支持的全部来源；指定单一来源时，这两个字段只统计本次读取范围，其他来源计为零。`matched` 始终是当前来源与搜索条件共同筛选后的数量。这样查看心情时不需要读取学习账或审计文件，也不会被无关文件损坏阻断；查看全部来源时仍会如实报告读取错误。

## 本轮落地

偏好页从五张卡合为三组：刷视频偏好、角色与陪伴、报告与参考。类别、喜欢词与发布时间直接可见，精细选片和低频陪伴设置按需展开，折叠摘要显示当前时长、避开词、探索比例或通知状态。关键词只有一个保存点。运行页保留模型、时长与启动入口，轮数和 token 上限折叠显示；桌宠后台入口直达这份工作台，删除另一套参数/日志浮窗。

学习页分待审学习与记忆检索两个工作区，只加载当前需要的数据，切换保留各自查询与草稿，旧响应不能回退新视图。学习记录的显示、脱敏、来源与实践字段共用单条投影，不维护第二本账；统一检索一次扫描，旧学习超过1200条也不再被静默隐藏。

会话和后台共用一份浏览规则。实时上下文只更新配额、开关、偏好和进度，不重复整段接话说明；同次提示词组装共用一次状态读取，下一请求仍现读。相同工具进度不反复附加，后台接力的首提示词就能看到剩余候选、已完成和暂时不可读的候选。

字幕临时失败、其他读取者占用和真正无字幕分别处理：临时问题先做别的事，到建议时间后最多再建议重试两次；耗尽后保留未读事实，不伪装成已读或永久跳过。已有下一页依据时给翻页建议，后台接力的下一页指令携带原关键词和页码。连续三个空发现请求先给换源/整理建议，不被平台仍有更多结果的分页标记覆盖；错误不当成没有视频。没有引入额外模型调用、后台轮询或外部服务。

## 验收范围

本轮通过真实浏览器与 React 合成夹具检查桌面、手机、矮窗口；验证折叠摘要、键盘展开、唯一参数编辑点、保存草稿、按需请求、晚到回包与卸载。后端验证 source-first 读取、损坏的无关文件隔离、批准/撤销与分页、延后读取、后台首请求接力、旧能力撤销及停止不接力。源码与运行测试均保留发送授权、审核和未知结果保护。

固定合成配置下，启动目标与实时段的合计文本从5405字符缩为约4000字符，减少约26%；这不等于真实 token 或调用费用减少同样比例。后台现在复用同一份完整规则，因此不将后台首次提示词变短作为结论。

实际宿主检查从本机已安装归档只读加载作用域工具和目标驱动，在隔离临时目录与合成会话中验证，没有启动/重启真实 DSH、操作真实平台账号或推送发布。本轮验证不等于真实模型长期运行或跨进程崩溃恢复已验证。
