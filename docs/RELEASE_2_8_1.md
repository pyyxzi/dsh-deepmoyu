# 2.8.1 发布说明

日期：2026-11-13（北京时间）。本版提高首次安装的默认可用量，修复“新开会话刷”中人格已注入却被任务要求拉回汇报口吻的问题。GitHub、npm与市场安装来源分别核对，本文件不代替外部发布回执。

## 默认值

| 设置 | 2.8.0默认 | 2.8.1默认 |
| --- | --- | --- |
| 每日精选 | 5条 | 20条 |
| 每日动态上限 | 1条 | 3条 |
| 会话续轮上限 | 64轮 | 128轮 |
| 后台单趟时长 | 45分钟 | 60分钟 |
| 搜索缺省候选 | 10条 | 20条 |

精选只限制日报收录，不是总浏览量；会话轮数也不是固定视频条数。配置接口、设置页与启动参数同步，显式保存的旧值、零值、模式独立参数和搜索数量均保留。token预算仍默认0，不设置该项上限；公开发送和定时开关不会自动开启。热度筛选、永久判重、共享节奏、授权审核及平台退避保留。

## 会话表达

删除 `bili_say` 中“挑完一条必须解释理由”的要求，同步预设、随包章程、初始目标与实时提示。新开会话刷、当前会话刷、后台中的可见消息，以及工具前后接话和一轮结束的话，均按当前全局人格表达。有话想分享才说，工具进度已有流水，不再要求重复队列、选片理由或下一步计划。

默认大肥鱼强调好奇、容易看入迷、可爱活泼和善意嘴硬，性格体现于自然反应，不增加固定口癖、成句模板或卖萌动作。自定义人格完整覆盖默认性格；普通会话不注入。实时约定覆盖旧章程中强制解释的要求，个人章程原文件保留。使用者问进度或遇到需处理的故障时仍如实说明。
