# 2.8.0 发布说明

日期：2026-11-12（北京时间）。本版汇总 2.7.2 之后的人格、学习、连续浏览与热门筛选改造。GitHub、npm 与 DSH 市场分别检查；本文件不是外部渠道已完成更新的证明。

## 主要更新

- 默认人格更接近活泼、嘴硬心软的群友，允许短梗与轻度回嘴，减少摘抄、固定口癖、总结和说教；视频相关动态交代可辨认的来由。
- 全局人格编辑器置于互动设置首屏；保存后完整覆盖鱼模式 AI 表达，普通会话不注入。后台下一次模型请求使用当前人格。
- 学习页默认展示已批准经验，支持多词检索、来源、适用场景与例句查看；按实际话题召回。学习是上下文检索，不是训练模型权重。
- 修复会话输出截断后的续轮断链、后台接力空档停止、忙碌时提前消费定时窗口等问题。接力保留原模型、预算、偏好与绝对截止；真实错误、手停、无进展及预算时限继续生效。
- 新安装默认播放量排序、最低 5 万播放。未知热度先查详情，未达门槛不当新候选；显式直链、已读补查和评论回复保留原语义。旧偏好不静默覆盖，修改后新开一趟生效。
- 区分每日一趟和整个时段持续运行，支持跨午夜；人工停止保持至当前窗口结束。DSH 需保持运行，不提供操作系统关机唤醒。
- 调整本地小时发送额度并修复重复计数，保留授权、审核、共享连发、判重、未知结果保护及平台退避。额度不是平台认可的安全频率。
- 新增好奇心手帐与拾光回看，依据当前作用域真实字幕记录问题与收获；精简设置、按需加载并修复异步竞态。
- 修复发布 CI 启动、跨系统中文字体发现和缺字体字号回退；增加固定摘要核验的 CI 字体夹具，修正 macOS/Windows 临时目录别名及时间戳导致的测试误报。

## 升级

registry 安装可在工作台检查更新并升级，随后完全退出并重开 DSH，再新开浏览任务。源码检出或链接安装保持锁定，直接更新自己的源码，不通过 registry 覆盖本地改动。运行数据仍保存在原插件家目录；升级不自动开启任何发送权限，也不改变用户自定义人格。

## 验证与边界

发布前执行当前源码的 Node、Python、工作台、浏览器及模式隔离检查，并对实际 npm tarball 和源码 ZIP 做归档核验、隔离安装和完整源码回归。最终命令与结果见 [发布审查记录](RELEASE_AUDIT.md) 的 2.8.0 段落。

浏览器与宿主检查中的外部模型和平台使用受控数据，没有向真实账号发送评论、私信或动态。测试通过不保证所有模型的表达质量、任意 DSH 版本兼容、永不停机或不触发风控。各开发阶段的历史测试数字不累加为本版独立测试数。
