# 2026-11-13 新安装默认值与刷视频时的表达

新安装允许更长时间浏览，并为筛选留下更多候选。已经保存的配置继续按原值使用，不把升级当成重置。

| 设置 | 新安装默认 | 含义 |
| --- | --- | --- |
| 每日精选 `perDay` | 20 | 留片和日报的收录上限，不是浏览或互动总量，也不要求凑满 |
| 每日动态 `momentPerDay` | 3 | 启用动态发送后的每日上限；没有合适内容可以不发 |
| 会话轮数 `sessionMaxRounds` | 128 | 会话目标最多续轮数；兼容旧字段 `maxRounds` 的缺省值也为 128 |
| 后台时长 `backgroundMinutes` | 60 分钟 | 未配置连续时段时的一趟时长；正常工作干净结束后仍在剩余时限内接力 |
| 搜索候选 `bili_search.num` | 20 | 一次上游检索的候选数量，筛选后可能更少；不是必须观看或评论的数量 |

搜索仍保留显式 `num`，范围为 1–50。搜索、榜单和热门列表继续执行已保存的日期、时长、避开词与最低播放量筛选。默认播放量排序和 5 万播放门槛不变；播放量缺失先核对详情。更多候选不会变成低播放视频兜底。

会话和后台 token 预算、累计 token 上限仍默认 0，表示不设置该项上限；会话时长也仍默认 0。后台仍有独立墙钟截止，连续时段仍按已保存的结束时间运行。手动停止、异常、模式切换和实际用量门禁继续生效。

评论、楼层回复、动态、私信及成果投递的发送授权没有因默认数值增加而开启。定时调度也不会自行启用。`commentPerRound`、`replyPerRound` 是保留用于兼容旧配置的退役字段，不是当前每轮发送条数上限。

旧安装显式保存的精选 5、动态 1、会话 64 轮、后台 45 分钟，以及其他自定义值全部保留。显式 `perDay=0` 和 `momentPerDay=0` 仍表示不留精选或不发动态，显式 token 预算 0 也继续保留。尚未保存过的字段采用新默认；只修改其他设置不会顺便提高已保存上限。

设置页读取真实配置；接口字段缺省时使用同样的回退值。参数仍分别保存，会话和后台的新草稿不改变已启动任务。修改源码后需完全重启 DSH 才能加载新版本。

## 新开会话刷的口吻

原先人格已经注入，但 `bili_say` 工具说明还要求每挑完视频都解释理由，初始目标和模式预设也要求说“挑中或空手的理由”。这些要求会把普通聊天引向字幕质量评估、选片理由和下一步计划，即使是可爱人格也容易说成工作汇报。

现在 `bili_say` 是可选的本地接话，有话想分享才用，不强制每条或每轮开口。新开会话刷、当前会话刷、后台中的可见发言，以及工具前后的普通消息、一轮结束的话，都按当前全局人格表达。工具进度已经有流水和状态区记录，不要求另写一段，也不重复复述工具回执。

默认大肥鱼强调好奇、容易看入迷、对可爱事物偏心、得意会显摆、嘴硬但关心人，让性格落在关注点和自然反应上。她可以接短梗、吐槽，也可以安静看；不靠固定“本鱼”、颜文字、卖萌动作或整句模板补人设。不将普通感受包装成影评、内容摘要或说教。使用者认真问进度、遇到需要处理的故障、权限和预算问题时，仍简短如实解释。

保存自定义人格后，完全使用自定义性格与表达习惯，不混入默认可爱口吻；普通模式不注入。实时规则明确覆盖旧目标、旧章程中强制逐视频解释的要求，但不修改用户个人章程的字节。留空人格才使用本次更新的内置大肥鱼。

本次变更归入2.8.1，发布范围见[版本说明](RELEASE_2_8_1.md)；本文件本身不证明外部渠道已完成发布。加载时需本人完全重启DSH，再开启一趟浏览；当前正在运行的时长和轮数仍按启动时参数。旧安装的数值保留，如需加大可在设置中手动改为上表数值。
