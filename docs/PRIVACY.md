# 数据与隐私

## 本地保存

插件运行目录为 `<DSH_HOME>/bili-duty/`，默认位于用户目录的 `.dsh/bili-duty/`。它包含配置、B站登录凭证、浏览与判重记录、学习队列、发送审核、用量、角色记忆、表情图片和本地视频产物。卸载插件包不等于删除这些数据。

工作区记录镜像是另一份本地副本：当镜像功能已配置时，部分脱敏记录也会出现在所选工作区根目录。不要把自己的运行目录、工作区镜像或诊断附件直接提交到公开仓库。发布脚本只归档插件仓库中的源码文件，并拒绝已知运行数据与凭证文件。

## 哪些数据可能离开本机

| 功能 | 接收方 | 发送的数据 |
| --- | --- | --- |
| 扫码登录与内容交互 | B站官方服务 | 登录流程数据、授权凭证，以及搜索、读取或已授权发送所需的参数 |
| 模型对话、后台浏览、学习审核与分镜编排 | 用户在 DSH 选择的模型服务 | 当前会话提示词、允许读取的工具结果和任务上下文；可能包含已批准记忆、评论或已授权读取的私信 |
| 默认视频配音 | `edge-tts` 使用的在线语音服务 | 待合成旁白及音色参数 |
| GPT-SoVITS 配音（可选） | 用户配置的本地环境 | 参考音频、对应文字和待合成旁白；该环境及其外部连接由用户自行配置 |
| 安装依赖与下载工具 | 配置的包源、官方分发源及下载镜像 | 下载请求所需信息；二进制完整性校验不等于对第三方服务行为作保证 |
| 链接收集表情 | 用户选择的公网图片来源 | 图片下载请求；来源地址受网络与格式校验 |

“凭证保存在本机”不表示账号请求从不携带凭证，也不表示模型或在线语音处理完全离线。本插件不设置独立的遥测或运行记录上传服务。

## 对话隔离与控制

普通会话不挂载角色工具或新增角色提示内容。切换模式不会删除已经存在的聊天历史。后台任务属于显式启动或已保存计划的独立任务，不因用户打开普通对话而获得该对话的人格或权限。

评论、私信、动态、发送审核、学习审核、自动收集及自动配图具有各自的控制项。批准一条学习不等于授予公开发送权限。关闭审核也不会自动批准旧待审记录。

## 导出、备份和删除

退出 DSH 并确认后台任务已停止后，再备份完整运行目录。备份中可能含有效凭证，应按私人资料保存。界面中的“忘记”只影响对应记忆，不删除平台上已发布的内容；清空用量不清空永久判重。

需要完全删除插件数据时，先卸载插件并停止所有相关进程，再自行删除 `<DSH_HOME>/bili-duty/` 和已配置的工作区镜像。不要删除整个 `<DSH_HOME>`，以免影响其他插件或 DSH 配置。
